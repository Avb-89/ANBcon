# anbcon

anbcon — консольная утилита для работы с Apple Notes на macOS. Работает в терминале и как локальный MCP-сервер для ИИ-ассистентов.

## Что умеет

### Искать по заметкам

Ищет по заголовкам и тексту. Показывает короткие выдержки, по которым можно открыть нужный фрагмент с окружением. Для разового поиска рабочая папка не нужна.

### Работать с рукописью

Привязывает одну рабочую папку к одной заметке. Читает и ищет по главам, считает слова и иллюстрации. Сравнивает рукопись с последней просмотренной версией: показывает правки текста и отличает перенос рисунка от замены.

### Выгружать рисунки и собирать HTML

Сохраняет отдельный рисунок в PNG или всю заметку в HTML с иллюстрациями на своих местах. HTML можно открыть и распечатать в браузере.

### Установка на macOS

```
mkdir -p "$HOME/.local/bin" && cp ./anbcon "$HOME/.local/bin/anbcon" && chmod +x "$HOME/.local/bin/anbcon"
```

```
echo 'export PATH="$HOME/.local/bin:$PATH"' >> "$HOME/.zshrc" && source "$HOME/.zshrc"
```

При первом обращении к заметкам разреши терминалу управлять Apple Notes. Полный доступ к диску не нужен.
